Risk & reliability

Security review

Use this checklist to guide a first-pass review. It is not a real security scan.

1
Validate and constrain input

Never trust client-side input alone. Validate values on the server when a backend is added.

2
Keep secrets out of source code

Never commit API keys, access tokens, passwords, or connection strings to a public repository.

3
Use safe DOM updates

Prefer textContent for user-provided text rather than injecting untrusted HTML with innerHTML.

4
Check dependencies and permissions

Use trusted packages, review permissions, and keep dependencies updated.
